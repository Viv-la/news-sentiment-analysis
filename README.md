# Financial News Sentiment Analysis

## Project Overview

This project analyzes the relationship between financial news sentiment and stock market behavior for Nova Financial Solutions. The analysis combines financial news headlines with historical stock price data to explore whether news sentiment can provide useful signals for understanding market movement.
